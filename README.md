
# 周报模板 Skill 配置与启动说明

这是一份从 **下载安装到开始使用** 的说明。

这个 Skill 的作用是：

* 读取你上传的周报模板
* 以后按这个模板生成周报
* 支持在界面里看 Markdown 预览
* 支持导出 Word

这个 Skill 适合放在 **同一个 Project** 里长期使用，因为 Project 会保留该项目里的聊天和文件上下文，方便后续继续沿用同一份模板。Skills 可以从 Skills 页面上传 `skill.zip` 安装；Skills 目前在 ChatGPT Business、Enterprise、Edu、Teachers、Healthcare 等计划中提供。([OpenAI Help Center][1])

---

## 一、先确认你能不能用 Skills

先看你的 ChatGPT 工作区是否支持 Skills。

官方说明里，Skills 目前提供给这些计划：

* ChatGPT Business
* Enterprise
* Edu
* Teachers
* Healthcare

另外，如果你的工作区是 Enterprise 或 Edu，Skills 在 beta 阶段可能默认关闭，需要管理员先开启。([OpenAI Help Center][1])

### 检查方法

1. 打开 ChatGPT
2. 点击左下角头像
3. 看菜单里有没有 **Skills**

如果你看不到 **Skills**，通常有两种可能：

* 你的计划不支持
* 你的管理员还没打开权限 ([OpenAI Help Center][1])

---

## 二、安装这个 Skill

你现在手里已经有一个文件：

* `skill.zip`

这是安装包。

### 安装步骤

1. 打开 ChatGPT
2. 点击左下角头像
3. 进入 **Skills**
4. 点击 **New skill**
5. 选择 **Upload from your computer**
6. 选中你的 `skill.zip`
7. 上传并安装

这是 OpenAI 官方支持的安装方式。Skills 页面也可以查看已安装、自己创建、别人分享给你的 Skills。([OpenAI Help Center][1])

---

## 三、第一次配置

这个 Skill **不会把模板写死在安装包里**。
正确用法是：**用户自己上传模板，然后在同一个 Project 里长期复用。**

### 第一步：新建一个 Project

建议你专门建一个 Project，比如叫：

* 周报
* Weekly Report
* 我的周报模板

Project 适合这种“长期重复使用同一份文件和上下文”的场景，因为它会保留这个项目里的聊天和文件。([OpenAI Help Center][2])

### 第二步：把模板放进这个 Project

把你的周报模板上传到这个 Project 里。

支持的模板格式：

* `.txt`
* `.md`
* `.docx`
* `.pdf`

不支持 Excel。

### 第三步：在这个 Project 里启用并使用 Skill

安装好 Skill 之后，在这个 Project 的聊天里直接开始使用它。
因为 Skill 安装后，ChatGPT 会在合适的时候自动调用它。([OpenAI Help Center][1])

---

## 四、怎么启动使用

配置完成后，真正“启动”的方法很简单：

### 启动方式 1：直接发一句话

在同一个 Project 里输入类似的话：

* 用我上传的周报模板生成本周周报
* 按这个模板先给我一个空白填空版
* 按我项目里的模板，把下面这些内容整理成周报
* 用上次那个模板继续写这周周报

### 启动方式 2：先让它识别模板

如果这是第一次在这个 Project 里用，你可以先说：

* 先读取我刚上传的周报模板
* 先解析这个模板，告诉我有哪些栏目
* 把这个模板转成可填空版本

这样它会先识别：

* 标题
* 顺序
* 固定文字
* 哪些地方需要填写

然后你再继续填本周内容。

## 五、标准使用流程

这个 Skill 默认按 **3 步** 用。

### 第 1 步：上传模板

只在第一次需要做，或者你换了模板时再做。

你把模板上传到同一个 Project 里。

### 第 2 步：输入本周内容

你把这周的内容直接发给它就行。
哪怕只是很乱的要点也可以，例如：

```text
这周完成了登录页改版
和后端确认了接口
修复了2个 bug
风险是联调时间有点紧
下周计划完成提测
```

### 第 3 步：选择你要的输出

你可以让它输出三种结果：

1. **Markdown 预览版**
   方便你直接在界面里看

2. **结构化 JSON**
   方便做系统对接或保存结构

3. **Word 文档**
   方便直接交付或发给别人

比如你可以直接说：

* 生成 Markdown 预览
* 同时给我 JSON
* 导出成 Word

## 六、最常用的几句命令

把下面这些话直接给用户就行。

### 第一次配置模板

* 读取我刚上传的模板
* 解析这个周报模板
* 先告诉我这个模板识别出了哪些部分
* 把这个模板转成可复用的填空版

### 生成空白版

* 按我的模板生成一个空白填空版
* 给我一个下周可以直接填的版本

### 生成已填写版

* 按我的模板，把下面内容整理成周报
* 用上次模板写本周周报
* 按模板填好并输出 Markdown 预览

### 导出

* 把结果导出成 Word
* 同时给我 Markdown 和 JSON
* 生成 Word 版本给我下载

## 七、什么时候要重新配置

只有这几种情况才需要重新配：

### 1. 你换了周报模板

比如公司换了格式，或者你想改栏目。

### 2. 你不在原来的 Project 里了

这个 Skill 推荐在**同一个 Project**里长期使用。
如果你换了 Project，新项目里没有那份模板，就要重新上传。因为 Project 才是保存该项目聊天和文件上下文的地方。([OpenAI Help Center][2])

### 3. 你上传了多份模板

如果同一个 Project 里有多份模板，系统通常会优先用最近确认的那份。
最稳妥的做法是直接说一句：

* 使用我刚上传的这份模板
* 不要用旧模板
* 以后都按这份模板来

---

## 八、用户最容易出错的地方

### 问题 1：装了 Skill 但没上传模板

这个 Skill 不是安装完就自动有模板。
它需要你自己先把模板放到 Project 里。

### 问题 2：模板传到普通聊天里，不是在 Project 里

这样下次很可能接不上之前的模板。
正确方式是：**固定在同一个 Project 里使用。** ([OpenAI Help Center][2])

### 问题 3：换了模板但没明确说

如果你上传了新模板，最好加一句：

* 从现在开始按这份新模板生成

### 问题 4：以为 Skills 页面就是启动入口

不是。
**Skills 页面是安装和管理入口。真正启动是在聊天里使用。**
也就是先安装 Skill，再回到聊天或 Project 里发指令。([OpenAI Help Center][1])

## 九、一页版傻瓜流程

给最终用户最简单可以只写这段：

### 配置

1. 打开 ChatGPT
2. 左下角头像 → **Skills**
3. **New skill** → **Upload from your computer**
4. 上传 `skill.zip` 安装
5. 新建一个 Project
6. 把你的周报模板上传到这个 Project 里

### 启动

1. 进入这个 Project
2. 发一句话：
   **“按我上传的周报模板生成本周周报”**
3. 再把你这周的工作内容贴进去

### 导出

生成后再说：

* **“给我 Markdown 预览”**
* **“同时输出 JSON”**
* **“导出成 Word”**

## 十、给用户的推荐开场白

用户第一次最适合直接复制这段：

```text
我已经在这个 Project 里上传了周报模板。
请先读取模板，识别栏目和格式。
然后按这个模板帮我生成一个可复用的周报填写版本。
以后我只会提供本周内容，你按同一模板输出 Markdown 预览、JSON，并在需要时导出 Word。
```
